# capstone-music-project

🎵 Plimo (Playlist for your moment)

1. 프로젝트 개요
   - 개발 배경: 기존 음악 앱들은 사용자가 직접 태그를 클릭해야 하거나, 과거 청취 이력에만 의존하여 현재의 감정 상태를 실시간으로 반영하지 못한다는 한계가 있습니다.
   - 핵심 가치: 자연어 처리(NLP)를 통해 사용자가 입력한 텍스트에서 정밀하게 감정을 추출하고, 심리 케어와 개인화된 힐링 경험을 제공합니다. 

2. 주요 기능
   - 감정 분석 모델: 사용자의 텍스트 입력을 통해 10가지 세부 감정(감동, 기쁨, 당황, 분노, 불안, 비장, 상처, 슬픔, 신남, 편안)을 분류합니다.
   - 데이터 기반 맞춤형 음악 추천
     - Exportify와 Track Analysis API를 활용하여 자체 DB 내 약 203,000곡의 Audio Feature(Danceability, Energy, Loudness, Tempo 등) 데이터를 추출 및 보유하고 있습니다.
     - 각 감정별로 오디오 피처의 수치 범위를 세밀하게 분류하여, 데이터상으로 '기쁜 노래', '슬픈 노래' 등을 정의하는 객관적인 분류 체계를 구축했습니다.
     - 사용자의 감정 분석 결과와 음악의 오디오 특성 수치를 매칭하여, 현재 기분에 가장 적합한 음악을 정밀하게 추천합니다.
   - 자체 음악 DB 연동: Spotify API의 제약을 극복하기 위해 구축된 약 203,000곡 규모의 자체 데이터베이스를 활용합니다.
   - 추천된 음악 시각화 및 유튜브 연동: 추천된 음악의 앨범 커버를 제공하고, 클릭 시 유튜브로 연결되어 음악을 감상할 수 있습니다.

4. AI 모델 상세
  - 사용 모델: KLUE-ROBERTa-large
  - 데이터셋: AI 허브 감성 대화 말뭉치 등 총 86,600개의 데이터를 활용하여 파인 튜닝을 진행했습니다.
  - 분류 클래스: 기쁨, 신남, 비장, 편안, 감동, 분노, 불안, 당황, 슬픔, 상처 (총 10종).
  - 성능 지표
      - 전체 정확도(Accuracy): 77.4%
      - 가중 평균 F1-Score: 77.5%
      - Macro 평균 F1-Score: 82.8% (희귀 감정 클래스에서도 우수한 성능 발휘)
